# ubuntu-terminal-config

Curated, GPU-accelerated terminal emulator configurations for Ubuntu, with a
one-click installer and per-terminal quickstart guides.

> Status: scaffolding — full content landing shortly.

## Terminals

| Terminal   | Config format | Location                          |
|------------|---------------|-----------------------------------|
| Ghostty    | key=value     | `~/.config/ghostty/config`        |
| Kitty      | kitty.conf    | `~/.config/kitty/kitty.conf`      |
| Alacritty  | TOML          | `~/.config/alacritty/alacritty.toml` |
| WezTerm    | Lua           | `~/.config/wezterm/wezterm.lua`   |

## Quick start

```bash
./scripts/install.sh
```

See `docs/guides/` for per-terminal quickstart and advanced learning paths.
